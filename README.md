Planto 🌱
-
Planto is an iOS app that helps you take care of your houseplants. Set a watering reminder for each plant and get notified when it's time for a sip.

Main Features
-
Add a plant reminder with its name, room, light, watering days, and water amount
See today's plants with a progress bar that updates as you water them
Mark plants as watered, edit them, or swipe to delete
"All Done" screen when every plant is watered
Local notifications to remind you to water your plants
Dark and light mode support

Technologies Used
-
Swift and SwiftUI
MVVM architecture
Observation (@Observable)
UserNotifications
Xcode (iOS 17+)
